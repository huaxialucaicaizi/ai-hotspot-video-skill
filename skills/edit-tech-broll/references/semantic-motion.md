# 语义动效：同页展开，不做静图轮播

当用户要有参考片密度的知识讲解，或者指出成片“没什么动效”时，动效是需要实现和验收的交付内容。降低认知负荷意味着控制每刻的信息增量，不等于取消运动。

## 选择什么动

| 讲述任务 | 真实可见的内部变化 | 观众收益 |
| --- | --- | --- |
| 流程或因果 | 节点按原声出现，箭头沿方向绘出，最后落在结果 | 顺着讲述建立关系，而非先读一张完成图 |
| 两条路线或策略 | 先出现比较维度，再分别构建路线；正在讲的一侧加强 | 保留共同上下文，同时明确当前比较对象 |
| 真实UI中的某个动作/结果 | 播放真正操作，必要时局部镜头推进、焦点框移动或遮罩聚焦 | 找到具体变化；看得出输入、动作与结果 |
| 官方声明/截图证据 | 先有原图上下文，再聚焦相关原句，出现清晰圈注或高亮 | 能追溯证据，不把装饰截图当作证明 |
| 观点回收或限制 | 说明完成后让图退出或降低权重，人物自然回场 | 结论回到作者，给判断留空间 |

不要把所有目标都处理成“整页匀速推近”。这可以偶尔辅助观看，但不能替节点建立、局部重点与真实操作。轻量动画也必须有明确起止状态和语义收益；固定logo身份页、重要证据阅读段可以保持静止，记录原因即可。

## 动效分镜的最小内容

每条运动记录：所属段落、作用对象、起始状态、结束状态、触发原话、实际开始/结束时间、时长、缓动、注意力目标、结尾阅读停留和实测结果。多条运动可在同页依次发生；不因为“每行一镜头”而换背景。

示例仅说明设计，不提供假时间码：讲“信息进入”时输入节点由低透明度/轻位移进入；讲“进行整理”时画出连接路径并突出处理节点；讲“下一步”时结果节点显露。终态保留到完整解释结束。实际时间必须从原声测得。

短促的元素进入可从约0.25–0.6秒试起；连线和焦点移动随路径长度、文字阅读与原声调整。它们只是制作起点，不是强制模板。缓动应让观众看清落点；文字稳定后再要求阅读，避免反复弹跳、闪烁、同时运动的多处焦点。

## 执行和交接

- 渲染层需要保留可独立控制的元素、遮罩、图层或可操作的关键帧，不能只把已经合成的整页PNG当唯一资产
- 素材只有平面截图时，用非破坏性裁切、局部聚焦和注释；不要移动截图内部控件冒充实际产品操作
- 剪映通用包应附已渲染的B-roll运动片段，并提供实际存在的源文件/关键帧说明及动效分镜；一组PNG＋口头说“加动画”不是同等交付
- 没有可用渲染能力时，明确当前只能交动效设计，不能说动态成片已经做完
- 不规定每分钟动画数、切镜数或三种构图占比。根据讲述需要变化，静止也可以是有意的阅读状态

## 动效验收

1. 播放已编码的代表样片，先独立看B-roll层或裁掉人物、进度条和字幕的B-roll区域。需要运动的图必须真的发生目标变化
2. 对每种主要机制检查触发前、运动中、稳定终态，记录视频文件、时间点与实际观察。抽帧可辅助定位，不能代替连贯播放对速度、缓动、跳帧和可读性的判断
3. 再带原声播放，核对节点/高亮出现是否跟对应短语一致。不要提前揭示导致观众抢读，也不要说完才开始画
4. 整片复查；静止段应有阅读/证据/判断上的理由，不是实现遗漏。人物口型、字幕轮换、进度条或换页本身不能替代B-roll内部运动
5. 运动像素差只能证明画面变化，无法证明它表达正确；保留人工观察结果。没有播放条件时标明未验收范围，不声称通过

已完成的窄范围实现例子见 [实际动效样片](tested-motion-example.md)。它验证了编码结果中的状态变化；不代表本skill内置渲染引擎，也不代替其他项目的实际执行。
