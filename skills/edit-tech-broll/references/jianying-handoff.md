# 剪映交接：能导入什么就说什么

## 先记录环境

记录操作系统、剪映专业版完整版本、是否为 CapCut、媒体路径与字体。不要把剪映和 CapCut 的功能、版本或草稿结构视为完全相同。读取当前实际界面与官方说明；不能猜测默认草稿目录并写入。

## 默认可靠交付：通用编辑包

交付目录建议：

```text
project/
  final.mp4                 已实际制作并验收才提供
  source/original.mp4       原始 A-roll；不能再分发时说明如何放入
  media/                   每项实际 B-roll，名字和清单一致
  editable/                自制 SVG/设计源文件，按实际产出提供
  captions.srt             真正对齐最终时间轴的字幕
  storyboard.csv           语义、观点、画面作用、触发词、出处
  edit-manifest.json       本包的编辑说明，不是原生草稿
  edit-list.csv            入点、出点、素材入点、构图、变换与备注
  HANDOFF.md               版本、导入步骤、布局值、缺口、验证范围
```

没有产出的文件不保留空壳冒充交付物。单张图片需按清单设置持续时间；复杂动画可提供已渲染的无字幕 B-roll MP4，同时保留真正存在的可编辑源。

用户要求丰富动效时，附 `motion-storyboard.csv` 与已经渲染的B-roll运动片段，关键帧/缓动在实际可编辑源或交接记录中说明。只有PNG和动效文字设计时，交付级别仍是设计包，不能称为已完成运动素材；通用清单也不会自动在剪映执行动画。

## 人工导入流程

1. 完整解压到固定目录，保留原片备份；建立新项目，按交付说明设置比例、分辨率和帧率
2. 导入原片与实际媒体。先放原片并核对总时长，再按编辑清单的开始/结束时间摆放 B-roll；清单时间基于最终片时间零点，不是源素材自身时间
3. 对视频 B-roll 同时使用素材入点/出点，必要时预先导出恰好对应时长的片段。图片按指定持续时间放置，变换值与参考预览对照。别拖入一堆图片后用等长片段替代语义分镜
4. 字幕：先在实际版本寻找本地字幕/SRT 导入；用两条字幕的小样测试位置、编码与时间。若本版不支持，保留 SRT 供核对，并用编辑器实际可用的字幕流程重建，不能承诺一键导入
5. 原片已有烧录字幕时，SRT 可作为文字/时间参考，默认不叠加第二套字幕。不能声称已无损删除烧录字幕；未经授权不裁掉字幕区域或用模糊遮挡强行重排
6. 上下分屏按预览调整裁切、缩放和位置，不能拉伸 A-roll；禁用 B-roll 原音或按清单设置，避免盖过口播
7. 从头播放对照预览，抽查每个切点和最后一秒；保存，关闭，重新打开确认媒体未丢，再导出最终成片

剪映本次没有运行验证时，交付名称为“剪映用通用素材与编辑清单”，明确需要人工摆放。不能命名为“一键导入草稿”。

## 何时可以交付原生草稿

仅在用户确实要求且实际执行环境可用时评估原生草稿适配器。第三方库文档的支持声明不是本项目验证结论。记录库版本/commit、软件版本、操作系统和模板来源；不要自动安装未知脚本或降级软件。

最低验证：新建最小项目 → 添加一段 A-roll、一个图像 B-roll、一段视频 B-roll、两条字幕 → 在目标版本开档 → 检查路径、时间、层级、变换、字体和音频 → 导出 → 关闭重开 → 比较导出帧与预期 → 再处理全片并重复验证。

通过后附验证记录与备份原工程。不能修改用户唯一草稿原件。无法开档验证、媒体重连失败、版本加密/结构不明时退回通用包，停止往用户草稿目录写自制 JSON。

## 已核实资料与限制

[CapCut 官方字幕导入说明](https://www.capcut.com/help/how-to-import-subtitles)提供其桌面/Web 的字幕导入说明。这只能作为 CapCut 的来源；本包没有据此断言每个剪映版本支持相同入口，也不认为 SRT 导入等于整个时间线导入。核对日期：2026-09-30。
