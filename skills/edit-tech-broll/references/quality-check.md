# 验收清单

## 语义与事实

- 每镜头有明确作用；切点由原声触发，提前露出下一结论的画面不会破坏讲述
- 关键事实有匹配来源；官方宣传、作者分析、示意与实际操作区分清楚
- 关系图连线有依据；比较单位、时期与条件一致；没有把可能性改为确定性
- 未核实的专名没有被“漂亮标题”掩盖；疑点已告知作者

## 画面

- 在目标手机比例、不暂停观看，能读懂标题、关系、UI 重点和字幕
- 原始烧录字幕、人脸和手势没有被误裁、拉伸或盖住
- 上下分屏时 A-roll 在上、B-roll 在下；三个目标平台的发布预览中，口播字幕没有被底部文字区遮挡，下方 B-roll 的关键信息仍可见
- 每个品牌 Logo 正确；截图能辨认来源；自制分析不伪装成官方 Keynote
- 没有黑帧、占位图、错误素材、泄露的个人信息、字幕重复或读完前切走
- 三种构图按观点分配：人物判断给人、复杂证据给B-roll面积、简单对照可分屏；避免无目的变换
- 圆窗模式实际保留准确可读字幕；进度条在全片同一画布锚点，三种构图都避让，整片连续不重置；在目标平台预览核对遮挡

## 语义动效

- 对需要丰富讲解的项目，实际播放B-roll单层或排除人物/进度条/字幕后的区域：节点、箭头、元素和证据焦点确实随讲述变化
- 运动分镜不等于渲染证据；每种主要机制留下实际样片、触发前/过程中/稳定终态的时间点和观察结果
- 同页内部有展开，结尾有阅读停留；不以大量换页、整页无目的漂移、人物口型或进度线替代
- 与原声配合检查触发、持续、缓动、可读性、遮挡与作者回收；静止段有明确理由，无统一动画配额
- 静态缩略图与像素差不能单独证明动效验收通过；没有连贯播放或原声核对时说明尚未验证

## 声音与时间

- 原声顺序与含义保留；切镜不切断语音；B-roll 原音未叠响
- 原片若只加画面，应优先连续保留音轨。确需转码时记录，不把重编码称为 stream copy
- 按实测时长核对末帧与最后一句；字幕无漂移；片段素材入点与成片起点不混淆
- 原音应完整试听；若工具只能检查波形或容器，明确未听审，不声称声音已人工验收

## 技术

可用 FFmpeg 时进行全片解码检查，先确认实际安装和命令选项：

```sh
ffprobe -v error -show_format -show_streams -of json final.mp4
ffmpeg -v error -i final.mp4 -map 0:v:0 -map '0:a:0?' -f null -
```

检查退出码和日志，不仅看文件存在。实际抽看首、中、尾以及所有语义切点前后，静帧与音频检查不能互相代替。检查帧率、分辨率、音轨、像素格式和时长是否符合本次目标平台。

`validate_manifest.py` 仅检查结构、相对路径、素材引用、连续时间段和明显的证据状态矛盾。人工核实素材真假、版权和剪辑效果仍不可省略。
