# 素材与证据台账

给每个实际资产一个稳定 ID，分镜只引用 ID，避免换文件后对应关系丢失。文件用短名称和项目内相对路径，下载后保存本地副本，不将临时签名 URL 当永久源。

推荐每项记录：ID、文件路径、素材类型、原创/官方/授权/生成、原始来源 URL 或用户文件出处、标题、发布日期、获取日期、产品版本、支持的原句、裁剪时间/区域、权限说明、是否可用于最终发布、状态。

## 对原句负责

- 官方资料说明官方如何描述自己；要证明亲自试用或真实结果，必须有对应实测记录
- 真实截图需核对页面标题、产品、版本、日期、数字、上下文。裁剪不能切掉重要条件；放大只改变观看区域
- UI 演示展示必要输入、动作、结果和关键等待/错误。压缩等待时标明加速或省略；不把拼接装成一次连续成功操作
- 录屏避免个人账户、邮件、电话号码、未公开资料和凭证。先用演示账号/虚构任务，必要遮挡在发布前检查
- 官方 Logo 不自动意味着任何视频片段都能重用。记录授权、许可或需用户确认的发布条件；“公开可见”不是使用许可
- 情境素材可以帮助理解，但不能替具体产品、发布会或用户结果作证。生成场景应显式标示示意，不能以真实事件名命名

## 素材缺口策略

同一原句的真实 UI 拿不到：先找同版本的官方操作演示，再找官方功能说明/截图；来源只能证明“官方宣称”时按此呈现。如果都没有，用解释性自制图或作者回场，并标注未实测/待核实。不要换成无关 UI，也不擅自改作者原声掩盖缺口。

无法合法获得原始媒体：记录原始链接、拟用位置与替代画面；停止该资产的采集，不绕过登录、付费或下载限制。用户要求成片且该证据至关重要时，及时列出具体缺口及可接受替代。
