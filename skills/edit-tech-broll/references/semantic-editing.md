# 从口播到能剪的镜头

## 先划意思，再划镜头

完整转写保留原话；按一个完整主张或因果/对比关系切语义段。字幕可能因阅读被拆成多行，不等于要产生多个镜头。一个语义段可以包含数句，一个镜头也可覆盖多个相邻语义段。

给每段写一句观众问题，如“它到底能做什么？”“为什么会省事？”“这两条路线差在哪里？”。再写作者的回答和证据，最后选画面。

| 原声任务 | 视觉动作 | 降低负荷的办法 |
| --- | --- | --- |
| 声称支持某操作 | 放真实操作关键步骤，保留足够前后文 | 聚焦相关区域，少量圈注，不堆同时运动的标记 |
| 解释流程 | 输入→动作→输出的关系图 | 先显示骨架，随原声点亮当前一步 |
| 比较两种策略 | 相同维度的双路径或并排对照 | 对齐单位、层级和时间范围，不用面积暗示无依据的优劣 |
| 从功能转到个人判断 | 作者回场 | 暂停新增信息，让结论由人承担 |
| 对某一说法提出限制 | 保留同一证据，突出条件/缺口 | 不切无关画面；观众能同时看到说法与限定 |

## 可检查的剪辑原则

- 镜头起点以触发短语对齐，终点以解释完成和阅读完成共同决定。信息过多时简化图、延长同页或分层出现，不随意改语速
- 大多数画面保留一个主要关系；可用两个或三个节点构成关系，不能把关系删成互不相关的词
- 变化可以是局部高亮、移焦或新增一条连线，不一定换页。所有动效都应能回答“现在观众应该看哪里？”
- 先听原声决定语义切点，再将时间码量化到视频帧；不要按固定秒数向整片套模板
- 字幕贴原声，B-roll 的概括贴观点。二者不都铺满同一句话
- 保留表达中的犹豫、限定词与个人判断；尤其不能把“可能”“我觉得”变成确定的产品结论

## 演示：虚构练习句，不是任何产品事实

“它能把分散的信息整理到一起。真正有用的是，整理完以后你可以继续处理任务。但这并不意味着每一步都不用检查。”

1. 第一段若有实测：真实输入与整理结果；若没有实测：保留作者，标记素材待补，不能生成假 UI
2. 第二段：作者解读的“信息→整理→下一步任务”关系图；图上标“流程示意”，避免暗示某产品已经支持整条链
3. 第三段：保留同一流程，在检查节点停住，然后作者回场承担限制判断

不安排固定三秒切一次，不给这段虚构文字写假时间码。对具体 A-roll 完成转写对齐后再落实时间。
