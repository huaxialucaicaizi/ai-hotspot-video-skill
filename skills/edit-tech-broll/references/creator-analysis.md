# 创作者参考：观察与适配分开

需要具体链接或视频。只有创作者名字时定位准确账号并说明所选片；有同名或选片会明显改变方向时询问。只有封面/截图只能分析静态视觉，不能推断全片节奏。

能获得完整片时通看并听，再对关键切点抽帧。记录每条依据：参考标题/链接、时间范围、原声触发词、画面变化、持续对象、画面作用、节奏/音效、可迁移机制与置信度。不能凭抽到几张图声称完整逐帧拆解。

适配时把“参考用了什么”改写成“本片为什么需要这个”：

- 参考的真实案例镜头 → 本片对应功能的真实证据
- 参考的关系图 → 本片自己的因果、对比或流程
- 参考的人物回场 → 本片作者的反问、限定与结论

借鉴机制，不复制人物身份、台词、案例结论、整套专有视觉素材或精确镜头秒数。未获发布使用许可的参考片只用于分析，不嵌入成片。

未看到具体参考时，结果写成“按高信息密度知识解释视频的方法制作”；不能写“已复刻小Lin说/黄白”。后续拿到参考后再用时间码证据作差异检查。

本包附有 [两条用户指定参考的实际时间点取样](observed-reference-examples.md)，只在需要借鉴其表达机制时读取；不要把取样检查扩写成完整音视频分析。
