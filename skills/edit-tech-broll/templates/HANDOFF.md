# 本片交接记录

填写真实结果；不适用字段删除，不把此模板当完成记录。

- 交付级别：分镜 / 样片 / 全片 / 通用素材与编辑清单 / 已验证原生草稿
- 原片与成片：文件名、时长、尺寸、帧率
- 原声：保留方式；是否有删改/转码
- 烧录字幕：有/无；是否另加字幕
- 构图：上/下边界、人物位置、缩放与裁切、安全区
- 语义动效：哪些节点/路径/证据焦点实际运动，渲染片段与关键帧源，触发前/过程中/稳定终态的实测时间点，是否连贯播放验收
- 进度条：启用/未启用；整体时间进度；固定画布顶部/底部；具体坐标与章节名；目标平台截图校准结果
- 编辑器验证：操作系统、软件完整版本、适配器版本；开档/重开/导出结果
- 素材与字体：路径、来源、授权状态、缺失项
- 人工检查：实际看过/听过的范围；待核实的专名或事实
- 自动检查：manifest、probe、完整解码结果
- 导入说明：按本项目具体素材写步骤，别承诺未经验证的一键导入

若为通用包：本包的 JSON/CSV 是时间码编辑说明，不是剪映原生草稿。请依据清单人工摆放媒体。
